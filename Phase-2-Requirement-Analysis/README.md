# Requirement Analysis Phase

## Project Requirement

The project requires implementing a script-controlled ACL to restrict record access based on the Branch field.

## User and Role Requirements

A user named EEE User is created and roles bb1, bb2, bb3, and bb4 are assigned.

## Table Requirements

An Institution Details table is created with fields for Student Roll Number, Student Name, Faculty Name, Branch, Email, Phone Number, and Description.

## Record Requirement

Multiple student records are created with different branch values such as ECE, EEE, and CSE.

## ACL Requirements

READ, CREATE, WRITE, and DELETE ACLs are implemented with the required roles and conditions.

Administrators retain full access to the records.
